# Инженерный калькулятор — ikcalc.ru

Публичная сборка v0.1.

## Что уже есть
- справочник метрических резьб ГОСТ и Unified ASME;
- определитель по диаметру, шагу и TPI;
- просмотр размеров и допусков;
- адаптивный интерфейс;
- одинаковая стартовая страница «Справочник» на ПК и телефоне.

## Структура
- `index.html` — оболочка интерфейса;
- `css/app.css` — стили;
- `js/data.js` — база резьб;
- `js/gost-tolerances.js` — расчёт/данные метрических допусков;
- `js/app.js` — интерфейс и логика поиска;
- `assets/threads/` — место для утверждённых SVG-схем резьб;
- `service-worker.js` — миграция со старого offline-кэша на загрузку из сети.

## Источники данных
В интерфейсе указываются ГОСТ 8724-2002, ГОСТ 24705-2004, ГОСТ 16093-2004 и ASME B1.1-2024 в зависимости от записи.

> v0.1 — рабочая публичная версия. База и представление допусков продолжают проверяться и расширяться.
