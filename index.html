О базе

Текущая сборка содержит сочетаний резьб. Unified сформирована по ASME B1.1-2024, метрическая часть — по ГОСТ 8724-2002 и ГОСТ 24705-2004.

Для Unified в карточках доступны имеющиеся в базе пределы классов наружной и внутренней резьбы. Для метрической резьбы в этой сборке показаны основные размеры d/D, d₂/D₂, d₁/D₁ и d₃. Поля допусков по ГОСТ 16093 будут добавляться после отдельной верификации числовых таблиц.

Это рабочая инженерная база для точечной проверки. Если находишь расхождение с нормативным документом, фиксируем конкретную резьбу, параметр и строку источника и исправляем данные централизованно.
